使用文档

留灯是一个有自己电脑的 AI 助理。这份文档从安装讲到每个功能，十分钟读完就能放心交给它做事。

安装

从下载页选一个：

你要什么下载说明
Windows 上长期用Lamplit-Setup-版本.exe安装版，建桌面和开始菜单快捷方式，不需要管理员
不想装，放 U 盘Lamplit-Portable-版本.exe免安装，双击即用
安卓手机Lamplit-Android-版本.apk允许「安装未知来源应用」后安装
iPhone / 临时用浏览器打开电脑上的地址，输入配对码

安装包还没有做代码签名，Windows 会提示「已保护你的电脑」：点「更多信息 → 仍要运行」。代码全部公开在 GitHub。

数据放在 %APPDATA%\Desk，卸载不会删除；升级直接装新版，什么都不会丢。

接一个模型

留灯自己不带模型，用的是你自己的密钥，对话直接发给你选的服务商。

  1. 打开 设置 → 模型，选服务商：DeepSeek、通义千问、Kimi、智谱、豆包、硅基流动、OpenAI、Claude 等都在列表里；其他兼容 OpenAI 接口的服务选「自定义」。
  2. 填上密钥，点「测试连接」。模型框点一下会列出服务商现在提供的全部模型。
  3. 每个助手可以单独选模型：简单的活用便宜的，难的用强的。

推荐先用 DeepSeek：便宜、中文好、会用工具。再填一个硅基流动的密钥，语音输入、看图、画图、做视频就都能用了。

和助手一起做事

像对人说话一样说要做什么，比如「把桌面上的截图按月份归档」「查一下这台机器磁盘还剩多少」「给这张海报换个标题再出三版」。它会自己决定用哪些工具：运行命令、读写文件、打开浏览器、操作桌面程序、生成图片……

  • 可以建多个助手，各有自己的角色、记忆和对话；也可以拉一个群，让它们分工。
  • 它缺工具会申请：比如需要命令行而你没给，它会弹出一张卡片问你要不要给。
  • 长回复会分几条发，结论在最前面。
  • 它干活时你可以随时插话问进度，不会打断它。

长任务与停下

超过几步的活，它会先列一张清单，做完一步勾一步。到了单轮的步数上限会自动接着做，不用你一直回「继续」；连续没有进展会停下来告诉你卡在哪。

  • 需要你决定的地方（选哪个方案、登录、只有你知道的信息），清单会停在那一步等你回答。
  • 应用重启后，没做完的任务会自己接着做。
  • 想让它停：点输入框旁边的停止，或者直接说「停下」「别做了」「取消」，正在做的和整个任务都会停，做好的文件都还在。

工作区

工作区是助手们共用的文件夹：它写的文件、生成的图片和视频、下载的东西都放在这里，所有助手和你都能看到。默认在 %APPDATA%\Desk\workspace。

想放到别的盘（比如 D:\留灯工作区）：设置 → 权限 → 工作区 → 更改位置，填一个文件夹路径，确认后留灯会重启。原来工作区里的文件不会自动搬走，需要的话自己复制过去。

工作区之外，你还可以开放别的文件夹给它读（或读写），见下面的「权限与审批」。

添加机器

家里的旧笔记本、台式机、云主机，都可以变成它干活的电脑。设置 → 机器 → 添加机器，填地址、账号和密码，留灯会自动装好一切，大约半分钟。

  • Linux（Ubuntu、Debian、Rocky 等）：能 SSH 登录，账号有 sudo。
  • Windows 10 / 11：先在「设置 → 系统 → 可选功能」装好 OpenSSH 服务器，用管理员账号。
  • 添加之后它们会跟着这台电脑自动更新；晚开机的机器开机后也会更新上。
  • 左上角可以随时切换在哪台机器上做事。

看屏幕与接管

右侧「电脑」面板能实时看到当前机器的屏幕。遇到扫码、验证码、付款这类必须你来的步骤，助手会停下请你接管：键盘鼠标交给你，弄好了点「我弄好了，继续」。

  • 多块屏幕：「全屏」旁边可以选看哪一块，默认只看主屏，也可以「全部屏幕」并排。
  • 装了留灯的 Windows 电脑，屏幕服务随留灯启动和退出；添加的 Windows 机器用的是系统服务，开机就在。
  • 屏幕只在本机监听，只有配对过的设备经留灯转发才看得到。
  • 手机上接管时有触摸板模式、虚拟键盘和常用按键。

权限与审批

在 设置 → 权限 里，每台机器单独设置：

级别效果
谨慎几乎所有会改动东西的操作都先问你
标准日常操作自己做，删除、系统改动、发消息这类先问你
放手都让它自己做，只有危险命令还会问——适合专门给机器人用的电脑
  • 能访问的文件夹：只有工作区和你开放的文件夹；其他位置先问你，或者直接不许。
  • 禁止的命令：格式化、删系统这类内置拦下，也可以自己加词。
  • 一句话规则：比如「发邮件之前先问我」，它会照做。
  • 操作记录：做过什么、谁批准的、何时接管过屏幕都查得到。

登录与保险箱

需要登录网站时，留灯会弹出一个安全表单让你填账号密码。它们加密存在那台机器的保险箱里，助手直接填进网页，自己看不到，也不会发给 AI 模型。

应用的授权码、邮箱的授权码同样放在保险箱。任何想从脚本里读取保险箱的操作，不管什么审批级别都会先问你。

连接应用

设置 → 应用 里一键连接常用服务，助手就能直接用它们的接口做事，每一步按你的审批级别来：

  • 邮箱：QQ、163、126、Gmail、Outlook 等，填邮箱地址和授权码（不是登录密码）。可以连多个邮箱；整理、搬移、删除默认进「已删除」，能恢复。
  • GitHub、GitLab、Notion 等：点「连接」，在弹出的页面里登录授权即可。
  • 百度网盘、Runway、Suno 等也在目录里。

连上一次，会同步到你所有的机器。

编程助手（用你的订阅额度）

写程序、改项目这类大活，留灯可以交给这台电脑上已经登录的官方编程工具，用的是你自己的订阅额度，不按次花 API 费用：

工具订阅装好后登录
Claude CodeClaude Pro / Maxclaude
Codex CLIChatGPTcodex login
CursorCursoragent login
QoderQoderqodercn login（国际版 qoder login）
  • 设置 → 模型 → 用订阅额度的编程助手 里能看到哪些已装好、已登录，并给每个选默认模型（Cursor 和 Qoder 会列出你账号能用的模型）。
  • 碰到大的写代码任务，助手会主动说「这个交给 Qoder 做」；每次交出去之前都先问你。
  • 它们只在任务文件夹里改文件；勾了「运行命令」才会运行命令。
  • 留灯不读也不碰这些工具的登录信息。

看图、画图、视频、语音

  • 看图：发截图或照片，它能看懂。设置 → 模型 → 看图。
  • 画图：硅基流动（Kolors、Qwen-Image、FLUX）、豆包 Seedream、通义万相、智谱 CogView、MiniMax、OpenAI、Google Imagen。
  • 做视频：硅基流动（通义万相）、豆包 Seedance、通义万相、MiniMax 海螺、智谱 CogVideoX。视频在后台生成，好了会告诉你。
  • 语音：按住说话转成文字；回复可以朗读，每个助手能选自己的声音。

手机与飞书

  1. 电脑上打开 设置 → 手机 里的「允许手机连接」。
  2. 手机装上安卓 App，扫电脑上的二维码，就连上了。
  3. 在外面：手机和电脑都装 Tailscale，连不上家里网络时会自动改走 Tailscale，不用重新配对。

不想装 App：在 设置 → 飞书 里接一个飞书机器人，出门在外用飞书给助手发消息，结果、图片、视频都发回飞书；需要批准时回一句「批准」。

记忆、技能、定时任务

  • 记忆：它会记下你的习惯和偏好，每个助手各有一份，也有一份大家共享的。
  • 技能：做过的流程可以存成技能，下次一句话就能复用。
  • 定时任务：每天的简报、定期的检查，到点自己跑，你不在也照样做完。

更新与数据

  • 直接安装新版即可，助手、记忆、设置都保留；已添加的机器会自动更新到同一版本。
  • 留灯在 1.2.146 之前叫 Nightshift · 夜班，数据在同一个位置，覆盖安装就行。
  • 数据位置：电脑上 %APPDATA%\Desk；Linux 机器上在安装目录的 data 下。

遇到问题

它一直不回 / 回得很慢

看顶部有没有「这台机器内存快用完了」之类的提示；再到设置 → 模型 点「测试连接」，确认密钥和余额正常。

手机连不上

确认电脑上打开了「允许手机连接」，手机和电脑在同一个网络；在外面就用 Tailscale。

屏幕显示「无法连接到服务器」

点「电脑」面板的「刷新」。刚开机或刚切换屏幕时，屏幕服务需要几秒钟准备。

还是不行

到 GitHub 提一个问题，附上出错时的截图。
