连接你的 NightshiftConnect to your Nightshift

手机上用的是电脑端同一份界面。填上你电脑正在跑的那个 Hub 地址就行。

电脑上要用 ASSIST_ALLOW_REMOTE=1 HOST=0.0.0.0 npm start 启动（默认只监听本机， 手机看不到）。手机和电脑在同一局域网，端口默认 4390。 配对码留空也行：打开后夜班自己会显示配对页。
